# Ember Slate

A dark colorscheme for my editor and terminals.
Included: Kitty, Alacritty, Zed, Nvim

## Palette

| Name     | Hex       | Use                       |
|----------|-----------|---------------------------|
| bg       | `#0B0E14` | background                |
| surface  | `#10141B` | floats, status line       |
| elevated | `#161B23` | menus                     |
| fg       | `#FFFFFF` | text                      |
| muted    | `#8A96A3` | operators, delimiters     |
| orange   | `#F39F5A` | keywords, primary accent  |
| gold     | `#FFC66D` | functions, attributes     |
| teal     | `#63D6D6` | types, brackets, tags     |
| green    | `#A8D98C` | strings                   |
| blue     | `#7EA6E0` | info, hints               |
| red      | `#E5646D` | errors, deletions         |
| rose     | `#AE445A` | minor accents             |
